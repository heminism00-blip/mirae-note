# 미래노트 v1.2

투자 영상·자료를 담고 → **요점·인사이트·실제 적용안**으로 정리하는 모바일 웹앱.
"지금 보고, 미래에 적용."

---

## v1.2 요약
**유튜브 공유 → 자동 담기**(Web Share Target) 추가. 유튜브에서 공유 시트로 "미래노트"를 고르면 링크가 자동 입력되고 제목·썸네일·카테고리까지 자동. (안드로이드 크롬 · 홈 화면 추가 필요)

## v1.1 요약
**하이브리드** 방식 — 요약은 기존 AI(**릴리스AI** 등)로 뽑고, 미래노트는 **정리·누적**을 담당. 링크 넣으면 제목·썸네일 자동 + 릴리스AI 바로가기 + 카테고리 자동 추천, 요약·인사이트·적용상태로 누적.

## 주요 기능
- 링크(유튜브 등) 붙여넣고 **불러오기** → 제목·썸네일 자동(A안, 실패 시 수동)
- 카테고리 태그(반도체·금리·환율·ETF·심리·기타) + ⭐ 중요도(3단계)
- **3줄 요점 / 인사이트 / 실제 적용안**
- **적용 상태로 우선순위 인식**: 🟢 적용 · 🟡 적용 검토 · ⚪ 단순 참고 (색·정렬)
- 상태별·분야별 **필터** + 검색
- 브라우저 저장(localStorage) — 계속 누적

## 사용
- PC: 링크 열고 **북마크**
- 모바일: 링크 열고 **"홈 화면에 추가"** → "미래노트" 아이콘으로 실행

## 파일 구성
| 파일 | 용도 |
|---|---|
| `index.html` | 앱 본체 (단일 파일) |
| `manifest.json` | 홈 화면 설치용 앱 정보 |
| `icon.png` | 앱 아이콘 (512×512) |
| `README.md` / `CHANGELOG.md` / `MASTER_PROMPT.md` | 문서·이력·명세 |

## 배포 (GitHub Pages)
- 새 저장소(예: `mirae-note`) 만들고 이 파일들 업로드 → Pages 켜기(main /root)
- 수정 시 파일 교체 업로드 → 자동 재배포

## 로드맵
- **1단계 (현재):** 내가 링크 넣고 수동 정리 + 자동 제목/썸네일
- **2단계 (예정, 서버 필요):** 키워드로 영상·뉴스 자동 수집 → 선별 → 메일/문자 발송
  - 서버 + API 키(YouTube/뉴스) + 발송 서비스 필요, 월 비용 발생 → 1단계 검증 후 결정
